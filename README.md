# Prática Estatística II — Atividade 4

Trabalho de Davi Lucas e Marcos Paulo, da Universidade Federal Fluminense.

Nesta apresentação, analisamos um artigo que compara a alimentação de bebês prematuros pela técnica sonda-dedo (TSD) e pela seringa de 20 mL. O foco é entender os testes estatísticos usados e interpretar os resultados.

## Como ver os slides

Abra o arquivo `docs/index.html` no navegador.

## Como editar

Baixe a pasta completa e abra `Atividade3.Rproj` no RStudio. O arquivo dos slides é o `index.qmd`.

Se faltar algum pacote, execute no Console:

```r
source("R/instalar_pacotes.R")
```

Depois, abra o `index.qmd` e clique em **Render**. A apresentação atualizada fica na pasta `docs`.

## Arquivos principais

- `index.qmd`: conteúdo e código dos slides.
- `assets/apresentacao.css`: cores, fontes e espaçamento.
- `docs/`: apresentações prontas para abrir no navegador.
- `dados/`: dados transcritos do artigo.
- `R/`: funções e instalação dos pacotes.
- `apoio.qmd` e `painel.qmd`: materiais complementares.
